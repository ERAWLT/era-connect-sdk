# Contributing

## Layout

- `packages/connect` — the published SDK (`@hwlt/era-connect`).
- `examples/expo-demo` — offline React Native demo (not published).
- `docs/` — the integration guide; `docs/protocol/` is the normative wire
  spec (synced manually from the protocol source of truth — do not edit the
  copy here without a matching upstream change).
- `packages/connect/test/fixtures/dart-golden.json` — golden vectors
  generated by the reference implementation. Regenerate only alongside a
  protocol change, never edit by hand.

## Developing

```sh
pnpm install
pnpm --filter @hwlt/era-connect test        # vitest
pnpm --filter @hwlt/era-connect typecheck
pnpm build && pnpm --filter @hwlt/era-connect exec publint
pnpm lint                                     # biome
```

Rules the codebase holds itself to:

- **No network I/O, no Node built-ins, no `Buffer`** anywhere under
  `packages/connect/src`. `Uint8Array` end-to-end.
- **Byte-exactness is the contract.** Request CBOR must replay the golden
  vectors byte-for-byte; wire-affecting changes need regenerated goldens and
  a protocol-spec update.
- **Errors are typed.** Every throw is an `EraSdkError` with a stable `code`.
- **Scanned input is hostile input.** New parse paths get bounds before
  allocations, and fuzz/property tests alongside.

## Releasing

Releases are driven by [changesets](https://github.com/changesets/changesets):

```sh
pnpm changeset        # describe the change, pick a bump
```

Merging to `main` opens/updates a "Version packages" PR; merging THAT PR
publishes to npm via trusted publishing (OIDC, provenance attached
automatically — no tokens in the repository).
